# Agent skills are vendored into the repo with the `skills` CLI

`mattpocock/skills` (27 promoted skills) and `michael-denyer/pstack-claude` (all skills except `tdd` and `teach`, which collide with mattpocock's) are installed with `npx skills add` into `.agents/skills/`. Claude Code reads them through symlinks in `.claude/skills/`, Cursor reads `.agents/skills/` directly, and `skills-lock.json` pins the source hashes. We chose this over Claude Code project plugins so the skills travel with the repo into cloud sessions and Cursor. The cost is that pstack's agents and its SessionStart routing hook are not installed, which is deliberate: the hook would route every task through `poteto-mode` and compete with the grill → spec workflow. Cursor users who want pstack's agents can run `/add-plugin pstack`.
